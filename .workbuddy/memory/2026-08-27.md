## Docker 构建报错修复（invalid target release: 17）
- 用户反馈 `mvn install` 报 `magic-api-servlet-jakarta: Fatal error compiling: invalid target release: 17`。
- 根因：`magic-api-servlet-jakarta` 与 `magic-api-plugin-springdoc` 两个模块 pom 显式 `<source>17</source><target>17</target>`，JDK 8 构建镜像无法编译。
- 修复：Dockerfile 构建阶段改用 `maven:3.9-eclipse-temurin-17`（JDK 17 可编译 1.8 模块 + 17 模块），运行阶段仍 `eclipse-temurin:8-jre`（应用为 Spring Boot 2.4.5 + javax，jakarta 模块在 javax 环境不加载）。
